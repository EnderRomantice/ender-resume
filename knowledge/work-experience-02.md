# 项目概述

Creatorone 是一个面向 TikTok Shop 商家的 AI 达人营销运营平台。它把达人发现、合作沟通、样品与 Campaign 管理、内容分析和后续跟进串成一套工作流，帮助运营团队减少重复操作，提高达人合作效率。

# 我的工作

我参与了 Creatorone 从 0 到 1 的完整产品建设，不只是单独开发某一层。前端部分包括运营后台架构、业务页面、国际化、埋点、状态管理、复用组件和交互体验；后端部分包括 API、认证授权、权限控制、接口契约和关系型数据模型；AI 部分包括 Agent 工作流、系统提示词、Memory、工具调用、任务执行与多轮上下文处理。我也参与了需求拆解、功能联调和问题修复，把商家操作、业务服务与 Agent 执行串成完整产品链路。

# 面试时的 1 分钟版本

我参与的是一个面向 TikTok Shop 商家的 AI 达人营销平台，核心目标是利用 AI Agent 提升达人运营效率。传统流程涉及达人筛选、数据分析、合作沟通、样品与 Campaign 跟进，工作量大而且信息分散，我们把这些环节整合到同一个产品中。

产品由运营后台、业务服务、AI Agent 能力和外部平台集成组成。我参与了从前端业务页面、后端 API 和数据模型，到 Agent 工作流与工具调用的完整开发。设计上把模型推理与确定性的业务操作分开：Agent 负责理解目标和选择动作，业务服务负责数据、权限与规则，让 AI 能参与真实工作流，同时保持系统可控。

# 技术架构

- 前端：Next.js、React、TypeScript、Tailwind CSS、SWR、Zustand
- 后端：NestJS、关系型数据库、REST / OpenAPI
- Agent：LLM Tool Calling、Skills、Memory、流式输出
- 工程能力：异步任务、外部平台集成、日志与可观测性

# 三个核心亮点

1. Agent 不只生成文本，而是通过受约束的工具参与业务流程。模型负责理解意图和选择动作，后端执行经过校验的确定性操作。
2. AI 能力与业务权限分层处理，不依赖提示词承担安全边界；数据访问和操作规则由业务服务控制。
3. 前端、后端与 Agent 使用清晰的接口和任务状态协作，让长耗时 AI 操作在界面上可理解、可追踪，也便于后续扩展。

# 核心业务链路：达人营销自动化

以达人营销自动化为例，运营人员设定目标后，Agent 会结合授权数据完成分析和内容生成，再由业务服务执行后续动作。前端持续展示任务状态和结果，异常操作则进入可恢复的处理流程。这里的重点是把不确定的模型输出放进确定、可校验的业务边界内。

# 项目难点

最大的难点不是接入模型，而是让 Agent 在真实业务里保持可控。我的处理思路是把真实操作封装成参数明确、可校验的工具，让后端服务继续作为业务事实来源；对于耗时任务，则通过异步执行、状态反馈和失败恢复改善可靠性。这样既能发挥模型的推理能力，也不会让模型直接承担数据一致性和权限控制。

# 不足与下一步

从这类项目中我形成的工程判断是：下一阶段的价值通常不只是换更强的模型，而是持续加强 Agent 的评测、权限边界、任务可靠性和可观测性。这些是通用的技术思考，不代表对 Creatorone 当前生产系统状态的披露。
