# 公司与方向

Wayline 做运营工作流系统：把客户零散的输入整理、推进为可验收的完成工作。每次合作聚焦一个工作流，事先约定清晰的验收标准，交付时提供真实的证据。我从 2026 年 11 月 7 日开始以联合创始人身份参与，这是我目前的主要工作。

# 我的角色

我是 Wayline 的联合创始人，负责四块：

- 获客：开发客户、做需求访谈，并把合作范围收敛到一个工作流和明确的验收标准。
- 技术架构：负责交付系统、内部工具与 Agent 技术栈的整体架构。
- 自有后台：搭建 Wayline 自己的管理后台，用来管理客户、项目和交付状态。
- Agent 交付工作流：开发用于执行、校验和交付客户工作的 Agent 工作流。
